# 🧠 Neuro-Forge: AI-Driven Drug Discovery Framework

Neuro-Forge is an advanced computational framework designed to accelerate the discovery of ligands for neurodegenerative diseases. By integrating Graph Neural Networks (GNN) with molecular descriptors, it provides rapid screening and safety profiling for potential drug candidates.

---

🚀 Key Features

Hybrid AI Scoring: Uses a custom GNN-based model to predict binding affinities and molecular scores.
*Safety Profiling: Automated calculation of **Toxicity (LD50)**, **BBB (Blood-Brain Barrier)  penetration, and Synthetic Accessibility (SA Score)**.
Neuro-Centric Design: Optimized for ligands targeting the central nervous system (CNS).
Interactive Dashboard: Built with Streamlit for a seamless researcher experience.

---

🛠️ Community Version
This version is optimized for high-speed preliminary screening using AI-based estimation.
